# Employee Management System

A Spring Boot CRUD application to add, view, edit and delete employees.
Built with Spring Boot, Spring Data JPA, MySQL, Thymeleaf, Validation and Lombok.

## How to run
1. Install XAMPP and start the MySQL module.
2. Create the database: `CREATE DATABASE employee_db;`
3. Check the MySQL username/password in `src/main/resources/application.properties`.
4. Run `EmployeeManagerApplication.java` (or `./mvnw spring-boot:run`).
5. Open http://localhost:8080
